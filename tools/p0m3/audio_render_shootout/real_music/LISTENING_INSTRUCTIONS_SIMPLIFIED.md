# Owner Blind Listening Instructions (Simplified)

Thank you for listening. This pack contains a small number of short
clips, grouped into transition sets. Each set has 2-3 clips (labeled
`A`, `B`, and sometimes `C`) that are the SAME musical transition made in
different ways -- you're comparing them against each other, not rating
them in isolation against some abstract standard.

## What to do, per set

1. Listen to all clips in the set (A, B, maybe C).
2. Pick your **BEST** one, your **SECOND** favorite, and your **WORST**
   one (letters only -- e.g. `B`, `A`, `C`). If a set only has 2 clips,
   leave WORST blank/skip it.
3. Answer four quick yes/no questions **about the set as a whole** (or
   about your BEST pick, if they differ noticeably -- use your judgment
   and say so in the note if it matters):
   - Would this be seamless enough for normal listening -- i.e. you
     wouldn't be annoyed if this happened automatically while you were
     just listening to music?
   - Was a volume dip or jump noticeable?
   - Was any tempo/stretch artifact noticeable (warbly, sped-up/slowed-
     down sounding, metallic, phasey)?
   - Did the timing/beat feel wrong at any point?
4. Optional: a one-line free-text note -- anything you noticed, in your
   own words.
5. Optional: an overall 1-5 score, only if you find it useful. `1` = very
   poor, `5` = excellent. You do NOT need to fill this in.

That's it -- no separate numeric rating for six different dimensions on
every single clip. Just your honest best/second/worst pick and four
yes/no answers per set.

## Please don't try to guess the technique

Clip letters are randomly assigned per set and carry no information about
how a clip was made. Just listen and react normally.

## When you're done

Return the filled-in ratings file. Please don't rename or reorder
anything in it.
