# AutoMix

Research and development project for a cross-platform music player and AutoMix engine.

Current project phase: **P0 — Feasibility & Reference Baseline**.

## Product direction

- Windows-first AutoMix prototype.
- Provider-independent analysis and transition engine.
- Local/DRM-free audio is the initial validation source.
- Spotify, Apple Music, YouTube Music and other providers are adapters, not the core engine.
- Quality target: phrase/downbeat-aware transitions approaching or exceeding Apple Music AutoMix where technically and legally possible.

## Public-repository safety

Never commit credentials, cookies, API tokens, signing keys, DRM material, private account data, copyrighted audio fixtures, or provider secrets. Use local configuration and CI secret stores only.

## Development status

No production implementation is accepted yet. Phase 0 is evidence-gated research and architecture work.
